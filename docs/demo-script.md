# 3 分钟演示动线

目标：让面试官在 3 分钟内抓住一件事——**这套系统的价值不在用了几个 agent，而在边界写在哪一层。**
全程用值班台点，不敲命令。每段给出「看什么」和「说什么」。

## 0:00–0:20 主张先行

打开 README 首屏图。

> 这是一个 A 股值班台：研究在盘后、决策在盘前、执行保护在盘中、复盘在盘后。
> 一句话概括架构：**LLM 只产判断，不碰钱；每笔订单人工确认；全过程可回放。**

## 0:20–0:55 主链与两道墙

指图上的两个 🧊。

> 主链上有两道冻结墙。08:20 池锁定，引擎做量化门槛和硬雷浅筛；08:45 计划锁定，
> 引擎扫 SIG-001、聚合 stance、算出仓位和触发线。
> 墙之后，任何会话——包括我本人在聊天里——都加不了候选、定不了仓、改不了触发线。
> 这不是流程约定，代码里 `Pool` 和 `Plan` 是 frozen dataclass。

顺带指一下旁挂的资讯索引和 KB：

> 这两个是旁挂，可读可不用。我特意不让任何一个 agent 当别人的唯一信息入口——
> 那样下游就退化成提示词流水线了。

## 0:55–1:35 一天档案：先看引擎那一份

值班台 →「全天回放」→ 选 `2026-09-16` → 展开 `MORNING.md`。

> 这份是引擎写的，不是模型写的。每只标的：stance、目标仓位 bps、现仓 bps、冻结触发线、票数。
> 看 300750：三票是建仓、持有、减仓，极差 2，按规则**回落成中性持有**并记 conflict。
> 三个模型吵架的时候，系统不选边，它变回不动。这比多数 agent demo 里
> 「让 agent 再讨论一轮」要克制得多。

## 1:35–2:15 边界写在哪一层

同一个页面往下滚。

> 这份 `DECISION-dirty.md.REJECTED` 是 SIG-001 打掉的——模型在理由里写了「先卖掉 3 手」，
> 命中数量规则。注意它是**改名保留**，不是删除：坏判断也要能复盘。
> 引擎的处理是整份作废，同一份里另一只无辜的标的也不计票，不是把那一行删掉继续用。
> 金日子本身是干净的一天，所以这份作废件不在 examples 里，由这条测试现跑现造：
> `uv run pytest tests/agent/test_gates.py::test_sig001_hits_void_whole_file_and_rename -s`。

展开 `EVIDENCE-decision-gpt.md`。

> 这是它的取证流水，每次工具调用一行，带 adopted / rejected 和原因。
> 这一天 4 条全是 adopted；被拒长什么样，看这条测试：`test_quota_exhausted_forces_low_info`
> 把 iFinD 打到 10 次，后 2 次 rejected 原因是配额耗尽——那时候角色只能带着 LOW_INFO
> 出池，不许编一个看起来完整的答案。
> 再看这条 `recall`：它真去 KB 查了动量教训，并把 `[qlab-0012@2026-08-29]` 引成了证据。

## 2:15–2:45 唯一放行口

值班台 →「人工确认」。

> 左边是引擎数字，右边是 agent 评论，两栏物理分开——卡片上也一样，agent 的话一律标「评论」。
> 微信卡片只有链接没有按钮。这里必须有一条 `intent_id`，而且它得存在于一轮**真实用户消息**里：
> 定时任务、子代理回传、聊天里写着「请确认」的三个都不算。
> 底下这条测试专门伪造了一个 cron 来源的 intent，断言它被拒。

## 2:45–3:05 收尾：我不证明什么

值班台 →「评测」。

> 162 个测试、覆盖率 96%、KB recall@5 0.90，两条没命中的我也留在文档里没删。
> 5 条实验轴关掉了 4 条，唯一活着的那条变成了池锁定的成交额门槛——它不是收益来源，是回撤刹车。
> 这套东西没跑过实盘。它证明的是我知道哪些东西不该给模型，
> 而且我把「不该」写成了跑不过就发不了的测试。

## 预答问题

| 会被问 | 怎么答 |
|---|---|
| 模型是假的，有什么意义？ | 图、权限、配额、门禁、状态机、账本全是真的在跑；只有判断内容用 cassette 录放。可复现恰恰是重点——`test_golden_day_is_byte_reproducible` 断言两次跑出逐字节一致。 |
| 为什么不自动下单？ | 展示模式无券商通道是明令的红线。设计上即便接了通道也要人确认：十态里 `approved → queued` 必须带 intent_id，没有绕过确认的路径。 |
| RAG 为什么不用来查行情？ | 价格必须单源可审计；向量召回对「同标的不同交易日」几乎没区分度，最容易把上周的相似结论当成今天的事实。所以 KB 只收跨日结论，且有 20 条金标集在度量它。 |
| 多 agent 是不是伪需求？ | 三个决策实例不是为了并行加速，是为了拿到分歧。极差 ≥2 就回落中性——系统的输出比任何一个单体 agent 都保守。 |
| 禁互读靠什么保证？ | deepagents 的 `FilesystemPermission` deny 读他人结论，工具层拦。删掉提示词里那句约束，测试仍然红。 |
| 生产系统在哪？ | 另一个仓库、另一套框架，在跑，不复用这里的代码。这个仓库是给人看的参考实现。 |
